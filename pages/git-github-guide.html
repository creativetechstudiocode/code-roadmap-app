Working with Git & GitHub

A practical, task-based guide to the Git and GitHub workflows people actually run into — starting a repo, pushing to GitHub, fixing rejected pushes, removing files (including secrets), and moving a project between repositories. Pick a task from the sidebar. Commands adapt to your terminal below.

Git commands are identical across terminals — only a few shell commands (like deleting a folder) differ. Those swap automatically.
